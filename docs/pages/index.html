SIBENGKEL: Sistem Informasi Bengkel Terpadu

Platform web berbasis Laravel 13 dan PHP 8.3+ untuk mendigitalisasi operasional bengkel otomotif: manajemen transaksi servis, booking daring, e-commerce sparepart, portal pelanggan, pelacakan status publik, dan RESTful API Sanctum.

Laravel 13 & PHP 8.3+ Dual-Guard Auth & 3-Level RBAC Sanctum RESTful API 137 Blackbox Test Cases DevSecOps + SIDIK SAST/SCA
GitHub Repository PRD & API Spec Blackbox QA Report

Kapabilitas Utama

Operasional Servis & Nota PDF

Pelacakan progres pengerjaan (pending, proses, selesai), penugasan mekanik, analitik pendapatan 7 hari, dan cetak nota servis.

Portal Pelanggan & Booking Daring

Autentikasi terpisah pada guard customer di /masuk dan /portal, pengajuan jadwal servis, konversi otomatis ke transaksi, dan reset OTP.

E-Commerce Sparepart & Cek Status

Katalog /sparepart dengan keranjang persisten (cart_data), checkout dengan pengurangan stok, serta pelacakan publik /cek-status tanpa login.

Sanctum REST API & DevSecOps

Endpoint JSON terautentikasi Bearer Token serta pipeline CI/CD otomatis (Gitleaks, Trivy, SIDIK SAST/SCA, Composer Audit, PHPUnit PHP 8.3 & 8.4).

Quick Start (Lokal)

git clone https://github.com/radityobw/SIBENGKEL.git
cd SIBENGKEL
composer install
npm ci
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
npm run build
php artisan test
php artisan serve
